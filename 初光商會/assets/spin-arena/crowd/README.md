# 競技場觀眾動畫

這些是從遊戲真正的 Three.js 觀眾模型渲染、編碼而成的動畫，不是將靜態圖改副檔名。

- 拍手 clap：笑眼、雙手在身前合拍。
- 歡呼 cheer：張嘴笑臉、雙手高舉。
- 跳躍 jump：笑眼、小跳躍與抬手；最高跳躍位移約 0.20 模型單位。
- 揮手 wave：張嘴喝采、單手高舉揮動與歪頭。

每種動作 16 幀；基本版本有 GIF 與動畫 WebP。遊戲用的 -0、-1、-2 WebP 各錯開 5 幀，避免同種動作全部同步。三維版由 cheerSpectator 共用函式驅動，依觀眾編號與時間輪換動作及兩種喝采表情，人物根位置不移動。

3D 手部實測位移範圍約 0.085～0.272 模型單位，並檢查跳躍位移；持續保留觀眾原有站位，避免進入競技場或道路。

工具：本機 Three.js 程式幾何與動畫、瀏覽器渲染、Pillow 動畫編碼；非另外聲稱由 Google IMAGEN 產生。陀螺及灰色盤面使用之 image_gen 材質來源另見 ../materials-v2/PROVENANCE.md。
