# Release 63

- 滿疲勞員工立即離店，編組顯示休息中並鎖定當日派工。保留每真實分鐘回復1%的既有規則，但休息鎖到隔日才解除。
- 每次切換到新的一天，所有員工疲勞減50個百分點（最低0），不會因重開介面重複扣減。
- 自動疲勞替班仍從可上工的休息員工中挑最低疲勞者，原員工離店休息。
- 草原及洞穴敵人模型載入失敗會漸進重試；清除失敗的資產Promise，避免永久不顯示。大型首領使用模型範圍與畫面重疊判定，避免中心已出界但身體仍在畫面內時整個消失。
- 新增6款陀螺、收藏卡、實際低模外觀、技能動畫、專屬音效、能力及熟練度成長。使用內建image_gen獨立生成6張透明原圖，來源與提示詞保留於authoring/spin-arena/cards-v63。
- 聲望門檻：霜晶白虎55、滄海玄鯨75、荊棘靈狐100、磐岩巨犀130、熾日鳳凰165、星穹麒麟205。原有六款及已收藏內容保留。
- 連續兩局平手後，進入一勝決勝；雙方下一次實際勝出即可贏整場，平手仍不結算。
- 一般對手依聲望逐步使用較進階陀螺，避免剛解鎖競技場就由新秀使用最高階款式；外來高手仍可使用全系列。

驗證範圍：規則測試、3D與2D手機抽驗、新陀螺技能流程、草原與洞穴首領模型大絕後可見性，以及故意中斷一次GLB讀取後的自動恢復。未進行全專案回歸。
