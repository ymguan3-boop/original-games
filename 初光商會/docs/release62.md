# Release 62

- 陀螺音效提高音量，等待 AudioContext 完成恢復再播放；一般碰撞亦有音效，保留靜音設定。
- 被動與碰撞集氣均提高兩倍；雙方適用。
- RPG 裝備欄：輪盤／軸心／外環，背包只顯示目前持有的等級，換裝與卸下歸還原零件。
- 移除付費強化；勝利熟練度 +25%、敗北 +10%，每 100% 升一級，餘數保留，最高 Lv.20。
- 類型成長：攻擊型偏攻擊、速度型偏速度、防禦型偏防禦、持久型偏持久、爆發型偏攻速、平衡型平均。既有等級保留。
- 四項能力使用固定 180 上限雷達圖；裝備、等級與技能分開計算。
- 每場結算換一批姓名與陀螺各異的對手；Lv.4／5 基礎倍率為 Lv.3 的 1.2／1.4 倍，再加難度與個別能力差異。比賽中與讀檔不重抽。
- 商會晶礦停售，移除相關委託及現行事件，剩餘庫存依存檔進貨成本退款一次。其餘商品、陀螺與玩家進度保留。
- 洞穴與草原共用小怪攻擊規則：多數需接近 1.15，少數等同雙刀 1.68；小怪無長距離攻擊，魔王規則保留。出手後玩家走開即可躲過，舊存檔待發射的普通怪遠程攻擊取消。

驗證：本次規則測試、洞穴／草原實際戰鬥模擬、3D 390px／2D 320px 手機裝備與技能流程抽驗；不宣稱全專案回歸。
