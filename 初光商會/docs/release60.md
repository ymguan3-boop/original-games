# Release 60：戰鬥陀螺專屬必殺技動畫

- 六款陀螺皆有專屬 image_gen 原創特效：獅焰衝鋒、風翼迴旋、晶壁反擊、雷牙爆襲、聖耀守護、影刃連斬。
- 每款輸出透明 GIF，16 個不同影格、1.2 秒，包含蓄力、爆發與消散。原稿與完整提示詞保存於 authoring/spin-arena/skills。
- 遊戲以同影格 WebP 圖集同步模擬時間；只預載本場雙方的素材，最多同時顯示兩個 Sprite。同款鏡像對戰各自使用 UV，不互相覆蓋；暫停時停格，換局及關閉時清除並釋放貼圖。
- 換局清空前局特效佇列，避免時間重置後再次播放過期必殺技。
- 2D 與 3D 共用實際對戰 renderer；不更動傷害、能量、AI、勝負、報酬與存檔重置標記。

驗證：陀螺既有 9 項測試與新增 3 項動畫事件測試；GIF 影格、不同影格數與時長檢查；直立手機 2D／3D 的玩家按鈕與 AI 放招、六款鏡像對戰貼圖、到期清除及重複 dispose 抽驗。未擴大執行既知有 11 個既存失敗的全專案測試。
