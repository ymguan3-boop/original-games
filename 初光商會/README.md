# 初光商會（幻靈奇旅）

## 2026-11-05｜缺貨導購、後場休息隊列、員工巡視與五章主線

- **缺貨導購**：在貨架點「自動補貨」時若該商品庫房數量為 0，立即進入「商品採購」，切至正確分類並醒目圈出所需商品，提示採購後再由補貨員自動上架；手動補貨不足時也導到採購。採購仍需正常支付金幣、符合等級和倉庫容量。
- **員工真實分工**：選擇休息或被排為待命的員工走往店後牆排隊（依員工 ID 排序分配獨立後場位置），即使打烊日結也會繼續走完。工作人員若有任務依原邏輯補貨／鍛造／收銀；沒有排定任務時改為各職務輪流巡視、整理貨架、招待或整理庫房，收銀員在櫃台作業。只有觸發「收銀員閒得打瞌睡」等偷懶事件的員工才會在原地無所事事；疲勞超過 95 時自動退到休息隊列。休息角色不再重複顯示大型「休息」氣泡。
- **五章營業主線**：商會 Lv.1–Lv.5 各有章節名稱、故事與 4 項營業主線：累計顧客成交、營業額、滿意度、日結次數。主線全滿且資金足夠、當天已日結時，沿用既有價格與建造時間**自動開始升級施工**，不得跳過成本；資金不足時顯示缺口。Lv.5 最終主線完成後播放傳奇結局。
- **支線任務**：每章至少 2 件額外挑戰（巡店、員工人數、庫存、解決事件、員工訓練等），完成後可在「商會委託 → 章節任務」領金幣，領取狀態存檔且不可重複。**支線不阻擋升級**。
- **過關演出**：每次建造完成時顯示小型動畫過關畫面，使用輕量 CSS 星光、彩紙和關卡印章（不另外下載圖檔）。點擊進入下一章目標；支援減少動態效果偏好。原有營業帳、任務、員工和存檔保持相容。
- 新增驗證 `node --test tests/commerce-chapters-staff-restock-20261105.test.cjs`。建議以 Android 直式實測採購高亮、休息隊列、關卡顯示與升級過場。



## 2026-11-05｜事件提示去重、主管靠近自動解決、免費選項疲勞成本

- **同事件只顯示一次**：員工頭頂的事件名稱僅由高清、可點擊的 `actor-reactions` 顯示，不再在等級／疲勞卡重複列示。相同職務有多名員工時，依事件的 `employeeId` 只顯示在真正發生事件的員工頭上；舊存檔沒有 `employeeId` 時會回退找到對應職務員工。
- **等級／疲勞提示縮小**：保留可點擊員工的功能，改成大約 79–88px 寬的二行小標籤（名字＋Lv、疲勞＋迷你進度條），不遮住大部分人物。
- **主管巡店靠近即處理**：營業中開啟「主管巡店」，當主角走到有待解決事件的員工約 **1.65 個遊戲單位內**（收銀員因櫃檯阻隔放寬至 2.15），事件會自動完成；打瞌睡類事件先讓員工做驚醒彈跳動作，其餘事件做受驚反應，約 0.85 秒後跳出小型「問題已解決」通知，4.2 秒後淡出。保留原始事件紀錄、冷卻與加成，事件不會重複處理；切回一般店面視角不會誤觸發。
- **免費處理不是零成本**：一般員工事件在視窗選擇不花金幣的方式，**發生事件的員工疲勞 +8，其他員工各 +2**；免費處理顧客抱怨為主辦員工疲勞 +5、其他員工 +1；主管親自靠近的處理方式則疲勞 +6／其他員工 +1。缺貨、沒人收銀、顧客排隊抱怨不可只靠主管走近解決，必須實際補貨、指派或安撫。數值有上限 100 並同步更新效率、浮動文字和存檔；付費選項維持原本效果。
- **既有進度相容**：不更動既有事件 ID、員工技能、進度存檔版本，也不刪除 GIF/角色模型。只有新觸發的事件才記錄員工對應 ID，舊事件可繼續處理。

### 2026-11-05｜商店視角與貨架編輯防誤觸

- **平常自由視角**：在店內空白處拖曳，可切換單指平移或旋轉；左右箭頭可旋轉，＋／−可縮放，雙指手勢能平移、縮放。視角控制列在一般遊玩時保持可見。
- **貨架調整視角鎖定**：選取貨架或進行新貨架放置時，攝影機保持原本的位置、方向及縮放大小。單指、雙指、滾輪、旋轉／縮放按鈕與主管巡店視角切換都不會改變鏡頭；貨架自己的搬移和旋轉仍然有效。
- **解除鎖定**：完成、取消或點選地板空白處解除貨架選取，即恢復原來的自由視角；退出裝潢模式不會重新置中視角。
- **驗收**：`node --test tests/commerce-camera-lock.test.cjs`；請另於手機直式和橫式實測貨架拖動、旋轉及視角鎖定，確保不再發生畫面跟隨貨架轉動。

## 2026-11-05｜手機操作、顧客事件與首次事件引導

本商會使用獨立的 `firstlight_shop_v1` 本機存檔，主遊戲只會讀取等級以呈現主城的五階外觀。這次改版保留既有資產、貨架與交易帳簿，不重置已儲存的員工、商品或成就。

### 本次修正

- 返回幻靈奇旅：手機版按鈕移入「商會資訊」列第二排，桌面版仍保留獨立入口，返回前儲存進度。
- 顧客出口：已付款／生氣離場後先依門口路線移動，靠近出口縮小消失；路線受阻最多約 20 秒後安全退場，不改變已完成的銷售與庫存。
- 顧客情緒：缺貨先顯示問號約 2.2 秒；排隊達耐心約 65% 顯示等待、超過 90% 顯示生氣提示；真正超時才發生不滿離場與滿意度扣分。
- 買到商品時滿意度增加，顧客頭上浮現「滿意 +1」；不滿離場則出現「滿意 -1」。有清潔員時付款可能產生額外滿意度加成。
- 員工頭頂：訓練、表揚、壓力、疲勞、補貨與待處理事件等動畫圖示；訓練或激勵會顯示熟練度、士氣增量，升級時會顯示熟練等級。
- 首次事件教學：各類隨機事件、限時委託與首次可領商會成就有引導操作，已看過的項目永久記錄於商會存檔。

- 主管巡查可查看最近 30 筆已處理事件紀錄；重複發生的同類事件會依 instanceId 再次提示。
- 正式發布頁面不提供免費切換店面等級。僅在本機 localhost 加上 `?shopDev` 可使用試玩切換，避免跳過經營任務。
