# 初光商會（幻靈奇旅）

## 2026-11-05｜手機操作、顧客事件與首次事件引導

本商會使用獨立的 `firstlight_shop_v1` 本機存檔，主遊戲只會讀取等級以呈現主城的五階外觀。這次改版保留既有資產、貨架與交易帳簿，不重置已儲存的員工、商品或成就。

### 本次修正

- 返回幻靈奇旅：手機版按鈕移入「商會資訊」列第二排，桌面版仍保留獨立入口，返回前儲存進度。
- 顧客出口：已付款／生氣離場後先依門口路線移動，靠近出口縮小消失；路線受阻最多約 20 秒後安全退場，不改變已完成的銷售與庫存。
- 顧客情緒：缺貨先顯示問號約 2.2 秒；排隊達耐心約 65% 顯示等待、超過 90% 顯示生氣提示；真正超時才發生不滿離場與滿意度扣分。
- 買到商品時滿意度增加，顧客頭上浮現「滿意 +1」；不滿離場則出現「滿意 -1」。有清潔員時付款可能產生額外滿意度加成。
- 員工頭頂：訓練、表揚、壓力、疲勞、補貨與待處理事件等動畫圖示；訓練或激勵會顯示熟練度、士氣增量，升級時會顯示熟練等級。
- 首次事件教學：各類隨機事件、限時委託與首次可領商會成就有引導操作，已看過的項目永久記錄於商會存檔。
- 事件演出：保留既有插畫，另新增 10 個原創 48×48、每個 4 幀的循環 GIF，涵蓋八種員工角色與缺貨／生氣事件，並使用 CSS 動畫增強視覺，不依賴外部 CDN。
- 主管巡查可查看最近 30 筆已處理事件紀錄；重複發生的同類事件會依 instanceId 再次提示。
- 正式發布頁面不提供免費切換店面等級。僅在本機 localhost 加上 `?shopDev` 可使用試玩切換，避免跳過經營任務。

### 開發與驗收

運用 Node.js 執行：

```sh
node --test tests/commerce-events.test.cjs
node --test tests/merchant-entry.test.cjs
```

測試檔位於倉庫根目錄 `tests/`。

請以 Android 手機實際確認：
1. 直式畫面「返回幻靈奇旅」與商會資訊不重疊，點擊後儲存並返回主遊戲。
2. 顧客購物後完成唯一一次結帳，帶商品離開並從門口消失；阻塞的離場者亦會最終退出。
3. 貨架缺貨問號、排隊過久怒氣圖示、員工事件表情和滿意／經驗漂浮數字皆能顯示。
4. 各類事件第一次顯示引導，完成後重開網頁不重複教學；操作面板能正常互動。
5. 隨機事件展示的 GIF 能循環播放，事件處理紀錄與存檔一致。

以上程式碼與資料狀態已進行靜態／邏輯檢查；真實 Android 手機長時間操作、GIF 視覺細節及 GitHub Pages 更新後的表現仍須實機驗收。
