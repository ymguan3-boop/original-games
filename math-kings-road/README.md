# 數戰勇者：王者之路

適合臺灣國小二至四年級的第一人稱數學 RPG。玩家透過三選一答題攻擊怪物、獲得金幣、購買武器與盾牌，並利用護符大絕招拯救數光小鎮。

- 製作人：官毅明
- 現行公開版：https://sinnoh-summer-expedition.kyo1216kimo.chatgpt.site/
- GitHub Pages 預定網址：https://ymguan3-boop.github.io/original-games/math-kings-road/

## 遊戲內容

- 三種難度：國小二年級、三年級、四年級
- 各難度 50 題，共 150 題原創題庫
- 第一大關共 10 戰，第 10 戰為大魔王
- 答對攻擊、答錯受傷、戰勝後獲得金幣
- 商店、武器、盾牌、紙娃娃與四種護符大絕招
- 三頁自動播放繪本、自然語音、戰鬥音效與雙主題 BGM
- 遊戲進度儲存在瀏覽器 `localStorage`

## 開發階段與提示詞

以下內容是依實際迭代歷程整理的「可重製版」提示詞，不是逐字聊天紀錄。每個階段都先定義可驗收的成果，再進入下一階段，適合交給具備程式、視覺與瀏覽器驗證能力的 Agent 執行。

### 階段 1：教育目標與最小可玩版本

**目標：** 先完成能實際遊玩的核心循環，不把美術、商店與劇情同時綁進第一版。

> **代表提示詞：** 建立一個適合臺灣國小三至四年級的繁體中文數學網頁 RPG。第一版只做一大關、10 小關，每小關以一道三選一數學題進行戰鬥；答對攻擊敵人、答錯被攻擊，第 10 關是魔王。請先定義資料結構、戰鬥狀態、勝負條件與可驗收流程，再實作並用瀏覽器走完一局。

**完成內容：**

- React、TypeScript、Vite 的靜態單頁遊戲。
- 玩家 HP、敵人 HP、傷害、金幣、關卡與勝負狀態。
- 戰勝後前進下一關，並在大關最後顯示通關結果。

### 階段 2：臺灣課綱題庫

**目標：** 題目難度與臺灣國小課程接軌，同時避免直接複製受著作權保護的題目。

> **代表提示詞：** 查閱臺灣官方數學課綱、學習內容與常見錯誤概念，為國小二、三、四年級各建立 50 題原創數學題。每題必須有固定三個不重複選項、正確答案索引、解析、年級、主題與難度。題目內容要自行改寫與設計，列出參考來源，並以程式驗證題數、ID、索引及欄位完整性。

**完成內容：**

- 三個難度各 50 題，共 150 題。
- 涵蓋整數四則、乘除、分數、小數、時間、長度、面積、統計與幾何。
- 每次出題會隨機抽題，並重新洗牌答案位置，避免正解固定在 B。

### 階段 3：道路遭遇式戰鬥畫面

**目標：** 建立具有前進感的第一人稱道路戰鬥，而不是一般表單答題頁。

> **代表提示詞：** 將戰鬥改造成原創的第一人稱道路遭遇式 RPG：上方工具列整合玩家 HP、目前關卡、金幣、音量與重新開始；中央顯示正面朝向玩家的敵人；底部只占整體 UI 約三分之一，放題目、三個選項、提示與大絕按鈕。不得照搬既有遊戲的商標、角色或素材。

**完成內容：**

- 戰場、敵人、狀態列與答題區有清楚的視覺層級。
- 題目區縮減至底部約三分之一。
- 關卡資訊整併到上方工具列，並取消玩家等級制度。

### 階段 4：角色、怪物與魔王美術

**目標：** 以一致的原創風格建立可動畫化的視覺素材。

> **代表提示詞：** 參考使用者提供的人物特徵，設計可愛、正面、置中的見習勇者大頭照與全身紙娃娃基底；再設計 9 隻正面小怪與 1 隻比例更大、輪廓更鮮明的魔王。怪物要有待機、眨眼、搞怪、受擊與攻擊表情。請以透明背景多宮格一次生成同風格素材，再裁切、去背並輸出個別 WebP。

**完成內容：**

- 小怪正面面向玩家，具有循環待機與隨機搞怪動作。
- 魔王具有獨立比例、演出與較長登場對白。
- 素材统一转为 WebP，并保留明确的用途与来源说明。

### 階段 5：攻擊、受擊與過關演出

**目標：** 讓每次作答都有明確、連貫且不重複結算的回饋。

> **代表提示詞：** 為答對、答錯、敵人倒下與前往下一關建立完整時間軸。答對時依序播放玩家攻擊、命中特效、敵人受擊與扣血；答錯時播放敵人攻擊、玩家受擊與扣血；過關時先顯示最上層通關標記，再播放沿道路前進動畫，最後直接載入下一關的正確敵人。輸入在動畫期間必須鎖定，避免重複扣血。

**完成內容：**

- 玩家攻擊、怪物攻擊、雙方受擊、命中特效與合成音效。
- 通關勾選標記位於對話框最上層。
- 下一關先切換資料再揭露畫面，不會短暫出現前一關敵人。

### 階段 6：商店與紙娃娃裝備

**目標：** 購買後的裝備必須立即反映在商店預覽與戰鬥畫面。

> **代表提示詞：** 建立戰後商店與紙娃娃系統，只允許一把武器、一面盾牌與一枚護符同時裝備。以人物全身輪廓與肩膀、手掌、腰間錨點校正素材；武器與盾牌使用「手臂連同持有物」的整組透明圖，避免把物件硬疊在手上。商店圖示、角色裝備欄、紙娃娃及戰鬥手臂必須來自同一套主素材並同步更新。

**完成內容：**

- 購買、持有、配戴與切換裝備。
- 左右手語意固定：角色右手持武器、左手持盾；第一人稱畫面依鏡像視角正確呈現。
- 預覽框自動等比縮放且不溢出；手臂銜接肩膀，護符置於腰間身體上層。
- 預覽下方顯示目前所有裝備的附加能力總覽。

### 階段 7：繪本、村長委託與自然語音

**目標：** 用三頁繪本交代故事，且所有轉場由實際語音播放狀態驅動。

> **代表提示詞：** 製作三頁原創繪本，描述大魔王破壞數光小鎮、村長求助、勇者以答題拯救居民。圖片本身不要印文字；旁白字幕即時顯示於圖片上方，並以自然、活潑、流暢的繁體中文語音朗讀。每頁停留時間以該頁音訊的 ended 事件為準，第三頁語音完整結束後才彈出村長委託，不可用固定秒數搶先切頁。

**完成內容：**

- 三頁自動翻頁繪本與同步字幕。
- 村長多動作原創圖像、委託視窗及接受流程。
- 故事音訊、怪物台詞與魔王長開場白皆可受全域音量控制。

### 階段 8：難度、贈禮與場景差異

**目標：** 讓年級、題庫、場景與戰鬥數值成為一致的難度選擇。

> **代表提示詞：** 玩家接受村長委託後，提供簡單、普通、困難三種難度：簡單對應國小二年級與數字森林，敵人數值不變；普通對應國小三年級與秋天場景，敵人 HP、攻擊力乘 1.2；困難對應國小四年級與古羅馬戰場，乘 1.3。村長隨機送一枚護符並自動配戴，普通另送 100 金幣、困難另送 150 金幣，並用語音解釋護符的重要性。

**完成內容：**

- 三難度各自使用專屬 50 題題庫與背景。
- 難度、贈禮、裝備與關卡進度一併寫入版本化存檔。

### 階段 9：四種護符大絕招

**目標：** 把連續作答回饋轉化為具策略性的主動技能。

> **代表提示詞：** 新增單護符配戴制度。玩家累計成功攻擊 3 次，或實際受到 1 次攻擊，即可施放一次大絕；施放時先鎖定答題，再播放該護符專屬動畫與音效，最後套用效果。製作四種護符及一致的多宮格特效素材：蛋黃哥懶懶護符讓敵人替換成森林嫩芽蛋黃角色並跳過下一次攻擊；大蔥嗆辣護符讓下一次答對連續攻擊兩次；珍珠泡泡盾護符抵擋接下來兩次答錯攻擊；橡皮擦救援護符移除下一題的一個錯誤選項。

**完成內容：**

- 不同護符有不同充能提示、施放動畫、戰場特效、音效與狀態。
- 泡泡護盾、敵人替換、二連擊與擦除選項皆由明確狀態管理，重新開始後不殘留。

### 階段 10：音樂與場景切換

**目標：** 故事、一般戰鬥與魔王戰要能聽出明顯區別。

> **代表提示詞：** 準備兩組可循環 BGM：一般冒險戰鬥曲，以及同一首用於開場繪本與最終魔王戰的主題曲。建立中央音訊管理器，依畫面狀態淡入淡出、避免重疊播放；瀏覽器尚未取得播放權限時，在第一次玩家互動後自動解鎖並恢復正確曲目。以實際播放來源與瀏覽器檢查確認切換成功，不能只看程式條件。

**完成內容：**

- 故事／魔王主題與一般 BGM 分流。
- 音效、語音與音樂可共存並受靜音與音量設定控制。

### 階段 11：操作性、無障礙與存檔

**目標：** 讓小學生能清楚操作，也讓錯誤狀態可恢復。

> **代表提示詞：** 支援滑鼠、觸控與鍵盤選擇；按鈕要有清楚焦點、可讀標籤與足夠點擊尺寸。提示開啟後必須能再次關閉；上方加入重新開始並要求確認。使用版本化 localStorage 存檔，讀取失敗時回復安全預設值，避免壞資料讓遊戲無法啟動。

**完成內容：**

- 可開關提示、重新開始、音量與靜音。
- 行動裝置與桌面版都可完成故事、戰鬥、商店與最終關。

### 階段 12：效能、部署與開源整理

**目標：** 降低首次載入延遲，並確保子目錄部署不會遺失資源。

> **代表提示詞：** 盤點所有圖片與音訊，只保留程式實際引用的發布素材；將大型 PNG 轉成適當尺寸的 WebP，首屏必要素材 preload，其餘 lazy load。設定 Vite 資源基底與相對路徑，使遊戲可部署到 GitHub Pages 子目錄。建置後檢查輸出檔、HTTP 狀態、瀏覽器主控台與完整遊玩流程，再補上程式碼與素材授權說明。

**完成內容：**

- 首屏圖片預載、非必要素材延遲載入。
- 靜態建置可由 `/original-games/math-kings-road/` 開啟。
- 程式碼與素材採分開的授權／告知文件，移除開發暫存物與未引用的大型檔案。

### 階段 13：最終驗收提示詞

> **代表提示詞：** 請以全新瀏覽器儲存狀態進行一次端到端驗收：完成三頁繪本與語音、接受委託、各選一次不同難度、確認贈禮與題庫、答對與答錯、提示開關、累積並施放四種護符大絕、進商店購買和切換武器盾牌護符、檢查紙娃娃與戰鬥裝備同步、過關前進、進入下一關與最終魔王。同步檢查手機尺寸、鍵盤操作、音訊切換、console error、圖片 404、重新整理續玩與重新開始。將每項結果列成通過／失敗清單，修正後重新測試失敗項。

## 本機開發

需要 Node.js 22 以上版本。

```bash
npm install
npm run dev
```

## 建置與 GitHub Pages

```bash
npm run build
```

建置會更新資料夾根目錄的 `index.html` 與 `assets/`。將整個 `math-kings-road/` 資料夾放在 GitHub Pages 的發布分支後，即可由子目錄網址遊玩；所有圖片、語音與音樂路徑都支援 GitHub Pages 子目錄。

## 主要結構

```text
math-kings-road/
├─ index.html          # 可直接由 GitHub Pages 提供的完成版
├─ assets/             # Vite 產生的程式與樣式
├─ src/                # React / TypeScript 遊戲原始碼
├─ audio/              # BGM、故事與怪物語音
├─ monsters/           # 最佳化怪物 WebP
├─ storybook/          # 繪本 WebP
├─ paper-doll/         # 武器、盾牌與紙娃娃 WebP
├─ charms/             # 護符 WebP
├─ npc/                # 村長動作 WebP
└─ docs/               # 架構、美術與題庫來源說明
```
