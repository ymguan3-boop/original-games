# 幻靈奇旅：初光之境

[開始遊玩](https://ymguan3-boop.github.io/original-games/幻靈奇旅/) · [Blender 模型展示室](https://ymguan3-boop.github.io/original-games/幻靈奇旅/model-preview.html)

適合直式手機的原創 3D 探索、捕捉與小隊對戰遊戲。角色、61 隻靈獸、NPC、建物、室內與道具使用 Blender 製作並匯出 GLB；網頁使用 Three.js 顯示模型，沒有舊版的程式幾何角色替代品。

## 操作

- 手機：左下搖桿移動，右下投擲；投擲左側的「滾」可配合搖桿向指定方向翻滾，未輸入方向時向面朝方向翻滾。
- 電腦：WASD／方向鍵移動，Shift 翻滾；翻滾完成後可立即再次使用。其餘操作可使用畫面按鈕。
- 接近 NPC 自動開啟對話；走到建物入口後使用入口按鈕進入。
- 手冊「建物與居民」可查看介紹，點名稱即可自動導航。手動移動或按取消可中止導航。
- 捕捉靈獸後可在圖鑑查看 2D 插畫卡片及 3D 模型、編組小隊。部分進化型、傳說與獎勵靈獸需要先滿足解鎖條件。
- 拖曳空白場景旋轉鏡頭，雙指捏合／滾輪縮放；左上小按鈕也可旋轉與調整遠近。

## 內容

- 主角有具厚度的密集短髮、6 套造型，以及待機、走路、跑步、揮手、投擲、攻擊、受傷與翻滾動畫。
- 61 隻原創靈獸；體型依進化階段放大，保留舊存檔識別碼以支援進度相容，顯示名稱使用原創設定。
- 9 位 NPC、表情立繪、補給與冷卻機制；6 間可進入建物及室內配置。
- 61 張以本版模型為參考重新生圖的 Q 版 2D 插畫，血量、攻擊與技能資料由網頁呈現。
- 場景維持 8 隻可締約幻靈；捕捉同種越多，該種類的出現權重越低。
- 初光挑戰是主角在 3D 場地移動、翻滾閃避並投球對抗首領；幻靈競技則保留小隊回合對戰。技能有屬性特效、音效及燒傷、冰凍、暈眩、減防、加攻等狀態。
- NPC 對話有機會取得回復藥、裂甲粉、勇氣結晶及締約用品，遊戲進行期間也會不定時廣播並直接發放補給。
- 星穹挑戰塔接入使用者提供的三層魔物遊戲，替換成本版 Blender 主角；敵人進入武器範圍自動攻擊，原攻擊鍵改為切換武器。由手冊或守塔員進入，素材與強化紀錄獨立保存。
- 自動存檔保存在同一瀏覽器的網站儲存空間，可讀取相容舊版進度。移除匯入／匯出操作，重置遊戲需兩次確認；目前沒有跨裝置雲端帳號同步。

## 開發與素材

從儲存庫根目錄啟動靜態 HTTP 伺服器，再開啟「幻靈奇旅/」。不需後端服務，也不需執行 npm 建置。請勿以 file:// 開啟，瀏覽器可能阻擋 GLB／JSON 載入。

`authoring/` 保存 Blender 5.2 的 Python 製模來源及 Blender 原始檔；`models/` 為遊戲使用的 GLB。`data/spirits.json` 定義收錄名單，`data/display-names.json` 保存名稱映射。使用者提供的照片與交接 ZIP 不隨遊戲發布。

## 驗收範圍

本次抽驗三個區域：① 直式介面、8 隻幻靈、鎖定、連續翻滾與鏡頭；② 建物／NPC 導航、補給、重新整理接續存檔及重置確認；③ 2D 卡圖、道館投球、競技狀態／道具與挑戰塔的自動攻擊、武器切換。對戰難度未做完整平衡測試，實體手機效能與多指觸控尚未驗證。
