# 幻靈奇旅：初光之境

[開始遊玩](https://ymguan3-boop.github.io/original-games/幻靈奇旅/) · [Blender 模型展示室](https://ymguan3-boop.github.io/original-games/幻靈奇旅/model-preview.html)

適合直式手機的原創 3D 探索、捕捉與小隊對戰遊戲。角色、61 隻靈獸、NPC、建物、室內與道具使用 Blender 製作並匯出 GLB；網頁使用 Three.js 顯示模型，沒有舊版的程式幾何角色替代品。

## 操作

- 手機：左下搖桿移動，右下投擲；投擲左側的「滾」可配合搖桿向指定方向翻滾，未輸入方向時向面朝方向翻滾。
- 電腦：WASD／方向鍵移動，Shift 翻滾；翻滾完成後可立即再次使用。其餘操作可使用畫面按鈕。
- 接近 NPC 才顯示名字，再靠近即可開啟完整對話；走到建物入口後使用入口按鈕進入。
- 手冊「建物與居民」可查看介紹，點名稱即可自動導航。手動移動或按取消可中止導航。
- 首次締約會彈出直式 2D 收藏卡；重複締約的卡片飛入圖鑑累積羈絆。圖鑑保留 3D 模型及小隊編組。部分進化型、傳說與獎勵靈獸需要先滿足解鎖條件。
- 拖曳空白場景旋轉鏡頭，雙指捏合／滾輪縮放；底部中央的小型攝影按鈕也可旋轉與調整遠近。

## 內容

- 主角有具厚度的密集短髮、6 套造型與 12 種動畫。締約成功隨機歡呼或舉右手跳起，失敗隨機失落或蹲下捶地；這四個結果動作以 2.5 倍速度播放，其他動作維持原速。
- 61 隻原創靈獸；體型依進化階段放大，保留舊存檔識別碼以支援進度相容，顯示名稱使用原創設定。
- 9 位 NPC、表情立繪、補給與冷卻機制；6 間可進入建物及室內配置。
- 61 張以本版模型為參考重新生圖的 Q 版 2D 插畫，血量、攻擊與技能資料由網頁呈現。
- 場景維持 8 隻可締約幻靈；捕捉同種越多，該種類的出現權重越低。
- 初光挑戰使用電場、星霧、音波、森療四座 Blender 場景。守護幻靈只會推離、麻痺、減速或短暫封鎖投擲，不扣玩家血量；移動或翻滾避開警示，投球累積信任。通關後「勝利!!」漸現，該守護幻靈會在野外出現，維持總數 8 隻；未捕捉前每 180 遊戲秒播報，並播放守護旋律。捕捉到該次出現的幻靈後活動結束，未完成活動會隨存檔保留。
- 幻靈競技保留小隊回合對戰，技能有屬性特效、音效與燒傷、冰凍、暈眩、減防、加攻等狀態。
- 城鎮新增 26 塊短草區，採數種綠色頂點色、單材質實例化顯示；草地可穿越，不加入碰撞障礙。
- NPC 對話有機會取得回復藥、裂甲粉、勇氣結晶及締約用品，遊戲進行期間也會不定時廣播並直接發放補給。
- 星穹挑戰塔接入使用者提供的三層魔物遊戲，替換成本版 Blender 主角；敵人進入武器範圍自動攻擊，原攻擊鍵改為切換武器。由手冊或守塔員進入，素材與強化紀錄獨立保存。
- 自動存檔保存在同一瀏覽器的網站儲存空間，可讀取相容舊版進度。移除匯入／匯出操作，重置遊戲需兩次確認；目前沒有跨裝置雲端帳號同步。

## 開發與素材

從儲存庫根目錄啟動靜態 HTTP 伺服器，再開啟「幻靈奇旅/」。不需後端服務，也不需執行 npm 建置。請勿以 file:// 開啟，瀏覽器可能阻擋 GLB／JSON 載入。

`authoring/` 保存 Blender 5.2 的 Python 製模來源及 Blender 原始檔；`models/` 為遊戲使用的 GLB。`data/spirits.json` 定義收錄名單，`data/display-names.json` 保存名稱映射。使用者提供的照片與交接 ZIP 不隨遊戲發布。

## 驗收範圍

本輪以本機 Chromium 抽驗三個區域（驗證紀錄保留於本機，不隨遊戲發布）：

1. 直式介面與卡片：320／390／430 px 寬度的緊密快捷鍵、方形雷達、文字自適應通知、底部吸收提示與卡片資訊留白；圖片預解碼、收藏卡顯示期間背景渲染節流。
2. 初光試煉：四座真實 GLB 場景、阻礙與閃避、勝利漸入、實際出現活動、180 秒廣播、捕獲停止、存檔接續及守護 BGM。
3. 新動作與草地：12 種主角動畫、四個結果動作 2.5 倍速、NPC 近距標籤、26 塊可穿越草皮，並同步新版主角至離線挑戰塔。

頁面與遊戲錯誤均為零。時間功能透過測試頁推進遊戲時鐘與執行既有更新函式驗證，這些測試入口沒有寫入正式遊戲。對戰難度未做完整平衡測試，實體手機效能及真實多指觸控尚未驗證。

Three.js 與 GLTFLoader 採 MIT 授權，詳見 vendor 內原始碼授權註記及 THIRD_PARTY.md。

## 2026-10-13 介面與探索更新

- 鎖定與解除合併為同一按鈕，狀態由 `aria-pressed` 與准星／斷環圖示呈現。四個約 19.3 px 小圖示以 32 px 透明觸控範圍緊靠 76 px 締約鍵，保持間距與倒 L 排列；普通、高階、星耀換球採深金、青、紫色。
- 四個攝影按鈕移至底部中央，每個可見圖形為 22 px，觸控範圍為 32 px。搖桿提高，避開攝影鍵。
- NPC 初次對話一次呈現所有句子。冒險服改由大夢博士交談贈送，進入建物不會自動解鎖；穿著後每 15 秒吸收城鎮中可見的補給，補給維持 90 秒再生冷卻。場上道具採獨立材質、飽和色與光暈。
- 每 300 遊戲秒輪播攻略；守護幻靈出現期間改以每 180 秒出現公告為優先。補給仍發放，公告不被一般通知覆蓋。透明通知依文字長度縮放，冒險服吸收提示位於底部鏡頭按鈕上方。
- 飛行幻靈於 1.8–3 公尺離地高度飛行 20–40 秒，再平滑降落步行 6–12 秒；有 Fly 動畫時優先播放。尺寸讀取 `data/model-size-overrides.json` 的個別身高與最大寬深設定，避免寬型幻靈被單純身高比例放得過大。
- Blender 主角包含 Celebrate／JumpCelebrate／Disappointed／GroundPoundDisappointed 共 12 種動作；13 種具翼幻靈有 Fly。離線挑戰塔同步嵌入新版主角，模型與資料使用 `guardian-turf-v4` 版本參數。

本批瀏覽器操作與狀態驗收已通過，範圍詳見上述三區抽驗；實體手機與真實多指觸控尚未驗證。

右上方形雷達可直接觸碰展開或縮小，沒有額外縮放圖案遮擋地圖。場景遮擋系統逐組處理 6 棟建物及 50 棵樹，遮擋視線時漸淡至 24%，離開後恢復；地面、道路、湖面與行走碰撞不會取消。道具及遮擋材質獨立複製，避免影響其他模型。
