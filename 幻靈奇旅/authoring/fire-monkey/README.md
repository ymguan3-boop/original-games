# 火猴守護者（C囝仔 → C老猴）

兩隻都用主角小男孩（`../kid-hero/`）的骨架建模：關節名稱、樞紐位置、掛點、五官切換節點與主角相同，主角的 19 個烘焙動作可直接套用；另加 7 節尾巴與尾端火焰。主角模型本身不變。

| 存檔 ID | 名稱 | 模型 | 普攻 | 大絕 |
|---|---|---|---|---|
| raikou | C囝仔（1 階） | `models/spirits/fire-monkey-kid.glb` | 小火球：過肩丟出 | 大火球：蹲下集氣、頭頂火球越滾越大，雙手擲出 |
| zapdos | C老猴（2 階） | `models/spirits/fire-monkey-elder.glb` | 伸棍打：劈下，金箍棒往前伸長再縮回 | 三連棍：旋身橫掃 → 躍起劈地 → 伸棍突刺，轉棍收勢 |

兩張卡片都是火屬性、稀有、守護者、紫框；保留原存檔 ID、取得條件與連續擂台參戰 3 場的進階規則，肖像沿用原來的圖。

## 檔案

- `monkey-model.js`：兩隻的參數藍圖（C囝仔身體與腿縮成 0.76 倍、頭部放大 1.2 倍；金箍棒是獨立道具，棍身與前端套頭可伸長）。
- `monkey-actions.js`：各階的普攻與大絕。火球招式的「出手」對齊在整個動作的 48%（遊戲在這個時間放出火系投射物）。
- `export-monkey.html`：用本機開發伺服器開啟，匯出兩個 GLB（動作 Idle／Walk／Run／Wave／React／Hurt／Jump／Attack／Ultimate）。尾巴擺動、火焰跳動、金箍棒伸長、手上火球蓄力都烘焙在動作裡。
- `preview.html`：即時預覽（可切換角色、播放招式與特效）。
- `ref/monkeys.webp`：原畫參考。

## 遊戲整合

- C囝仔：火球在手上蓄力到出手瞬間消失，之後由遊戲既有的火系投射物接手；C老猴的招式以近身打擊為主，不另外射出投射物（`js/spirit-combat.js`）。
- 舊的原生控制器 `models/native/fire-monkey.js` 與相關程式碼已移除。
- 模型面數：C囝仔約 2.2 萬、C老猴約 4.0 萬三角面；GLB 約 1.1 MB／1.9 MB。
