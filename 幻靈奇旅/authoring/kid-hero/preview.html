道具掛點

手上的物品不屬於角色模型。每個動作預設會掛上需要的物品（例如雙槍動作掛手槍與槍口火光），也可以在這裡改掛別的物品，或載入自己的 .glb 測試。自製模型請以握點為原點：刀劍的刃朝 +Z、槍管朝 -Y、球以球心為原點。

掛點用途目前掛著改掛自訂模型
 
// 在程式裡替換：載入自己的模型，掛到右手（原點 = 握點、+Z = 劍身方向）
const gltf = await new GLTFLoader().loadAsync('my-sword.glb');
attachProp('propR', gltf.scene);       // 或改 props.js 的 PROPS.sword.parts
