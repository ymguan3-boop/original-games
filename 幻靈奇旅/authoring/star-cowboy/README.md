阿宏高度為遊戲主角 2.55 的 2/3。法師對齊三階貓女的世界尺寸覆寫 2.332。保留目前雷／念屬性，以及紅卡、傳說、魔王設定。擂台仍使用遊戲既有的獨立戰鬥展示尺寸。

## 原檔與輸出

- `ahong-cowboy.blend`、`starlight-mage.blend`：可編輯網格、材質、蒙皮與動作。
- `../../models/spirits/ahong-cowboy.glb`、`../../models/spirits/starlight-mage.glb`：遊戲模型。
- `../../cards/art/ahong-cowboy.webp`、`../../cards/art/starlight-mage.webp`：768 × 768 同模型渲染肖像。
- `preview.html`：兩席展示，可旋轉、暫停及選擇動作。
- `build.py`：Blender 建模與動畫來源；以 Blender 5.2 `--background --python` 重建。
- `../../js/duo-combat-vfx.js`：隨手部及動作時間同步的槍火／星環／星束效果，接入遊戲與模型室。

## 動作與持物

每支包含 Idle、Walk、Run、Attack、Ultimate、Hurt、Wave、React、Jump 九個動作。阿宏雙槍左右鏡像，前向拇指握持，打招呼時收起左槍。法師右手持杖、左手施法；裙襬、披風、馬尾與臉部有獨立骨架。

## 驗證

`check.cjs` 抽樣每組動作 25 個時間點，檢查蒙皮座標與地面界線，並產出動作截圖及肖像。最小採樣 Y：阿宏 0.0060、法師 0.0039。這是抽樣檢查，不代表所有網格組合均完成精密碰撞檢測。

`verify-runtime.cjs` 使用獨立瀏覽器測試環境，確認家族模型室、肖像、圖鑑及兩人實際對戰大絕。`game-verification.json` 記錄技能採原生動作與專屬特效，瀏覽器及遊戲錯誤均為空。

角色採風格化建模，與參考插畫的寫實布料、細密花紋及髮絲仍有簡化。

- 牛仔參考 `kid-hero/kid-actions.js` 的 `gunsReady` / `gunsCombo`：普攻右、左交替瞄準射擊；大絕右射、左射、雙槍齊射並後跳。手腕保持槍管朝前，出手與專屬特效使用相同時間。
