# 卡圖製作設定

本次採內建 ImageGen，參考每隻幻靈的實際 Blender GLB 模型畫面。每批四個角色依左上、右上、左下、右下位置生成四宮格，切割為獨立 WebP；最後一批只採用左上角。

共用視覺要求：可愛 Q 版 2D 卡通插畫、大眼睛、活潑生動的動作、鮮明輪廓；保留參考模型的物種外形、配色及可辨識特徵，各格使用配合幻靈屬性的場景與光效。不得混合不同象限的角色，不加入標題、卡牌數值、文字、浮水印或 UI。卡片資料由遊戲依圖鑑設定另外繪製。

每隻角色使用哪個模型、哪一批及哪一格，記錄於 [卡圖對照表](../data/card-art.json)。原始四宮格與實際模型參考圖保留在本機 phantom-card-work 工作資料夾，網站只發布切割完成的圖片。
