# 星冥收割者與死神鐮刀

保留既有服裝、武器存檔 ID 及模型路徑；舊存檔直接顯示新名稱，無須重新領取。

## 套裝

一般場景及洞穴每10秒吸取所有可拾取物品，包含洞穴經驗、點數、補品、武器及技能書。城鎮沒有落地經驗球，沿用現有補給物件；初光挑戰保留原投球規則。
主角攻擊倍率 = 1 + min(2.5, (1 - 目前血量/最大血量) × 5)。滿血1倍、75%血2.25倍、50%及以下3.5倍；回血即重新計算。適用有主角血量的攻擊流程，不套用寵物。

## 武器

洞穴基礎攻擊28、念屬性、範圍3.4，普攻五段各0.65倍，原始動作約2.79秒。挑戰塔沿用大劍基礎攻擊57及原普攻倍率，顯示分類為鐮刀。
鐮刀擊殺後攻速+50%（攻擊動作與命中時序縮短為原本的1/1.5），持續10秒；再擊殺只刷新，不堆疊。換武器不把增益套到別的武器；新局清除。
大絕冥月收割不需目標，3.6秒演出：死神現身→空洞雙眼發紅光→雙眼消失→畫面破空斬與玻璃碎裂聲→一次全場傷害。
結算時先固定含武器永久強化、融合、服裝、主角攻擊增幅的攻擊力，傷害基礎為其5倍；主角回復同一攻擊力的3%，不是總傷害的3%，不隨目標數量增加。沿用敵人防禦、元素、冰凍減傷、捕捉留手及洞穴魔王階段保護；本次大絕不額外暴擊，以免偏離固定5倍。大絕不受擊殺攻速加快。洞穴冷卻22秒（沿用冷卻縮減）；挑戰塔18秒。

## 表現與生命週期

刀氣使用重用的Three.js弧形網格，死神與鐮刀輪廓在3D場景呈現，紅眼及裂紋使用解析度隨視窗調整的向量畫布。演出採戰局時間，暫停不推進，死亡、離場與重開會清除，不會在背景補打。聲音受既有音效音量及靜音控制；洞穴使用與其他武器相同的前景混音與BGM降低機制。

演出分為不重疊的三段：死神現身 0–1.05 秒、紅眼 1.05–2.25 秒、劃破螢幕 2.4–3.6 秒；最後才結算傷害。死神使用金邊斗篷與血紅鐮刀素材，手持模型及刀氣同步改為血紅色。螢幕裂痕依電腦／手機視窗比例延伸至邊緣。

星穹塔武器商店與快速切換選單共用正確被動說明；死神鐮刀不顯示虛構的0%觸發率。擊殺後的攻速+50%在旅人血條下顯示秒數，暫停時不遞減；拾取戰利品時仍會計時，進入下一層可保留剩餘秒數，重試同層或新挑戰則清除。
