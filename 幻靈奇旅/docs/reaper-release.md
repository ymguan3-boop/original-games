# 星冥收割者與星輝鐮刀

寵物商人提供一次性密碼贈禮。領取旗標、衣櫃解鎖與目前服裝保存於主遊戲存檔；領取後隱藏贈禮選項。其他商店與寶箱不提供這把限定武器。重置遊戲會清除領取紀錄，與其他遊戲進度相同。

一般探索、室內與四個初光挑戰沿用投球玩法，死神服裝與單手持鐮外觀跟隨同一位主角；投球、翻滾、受擊及表情演出時收起武器，避免遮擋原動作。挑戰塔與洞穴讀取同一份領取旗標，各自保存武器裝備選擇，領取不會重複添加或覆蓋後來選擇的武器。

星冥連舞包含下斬、換勢、低掃、回斬、原地雙旋與收勢，整段約 2.79 秒，五次命中與共用動畫的揮斬時間一致。洞穴基礎武器攻擊 28、每段倍率 0.65；冥月收割前四段倍率 1.4，最後一段 2.4 並擴展至 6.2 單位，冷卻 22 秒。挑戰塔按既有大劍基礎攻擊及卡片／服裝加成計算，普攻每段 0.8 倍、大絕前四段 1.6 倍、末段 2.6 倍，冷卻 18 秒。正常傷害仍保留敵人防禦、迴避與場景規則。

驗證：278 項 Node 測試通過；瀏覽器實際操作錯誤／正確密碼、永久存檔、四個初光挑戰完整進場、城鎮與室內、挑戰塔與洞穴。戰鬥頁以固定步長推進實際模擬和動畫，確認五段傷害、雙手握點、大絕末段擴散與恢復單手持鐮，無角色顯示例外。套裝及握持控制另檢查三種模型縮放與 301 個連段取樣，手臂不穿入軀幹，手腕旋轉在限制內。合成刷刷聲共用全遊戲的音效音量與靜音設定。
