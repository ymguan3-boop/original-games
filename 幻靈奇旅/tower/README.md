# 星穹挑戰塔（2026-10-13 更新）

《幻靈奇旅》挑戰塔目前包含三層魔王：森棘龍、霜牙獸、熔冠翼龍。主角使用既有 Blender 模型 `../models/hero.glb`，沿用既有動畫與第三人稱手機操作。

## 操作
- 進入武器射程後會自動攻擊；手機右下角可切換大劍、雙刀、獵弓。
- 翻滾可中斷一般攻擊；大絕為冷卻制，三種武器分別使用三連斬、十連擊、箭雨。
- 頂部「商店」位於「返回初光鎮」左側，素材袋顯示已撿取的材料。

## 素材商店
- 商店提供 9 把永久兌換武器，各類 3 把，分別附帶冰凍、麻痺、中毒、擊退等效果。
- 兌換會扣除存檔內實際素材；購買後自動裝備，也可重新選取已購買武器。
- 新玩家僅有普通大劍；舊存檔保留既有基礎武器。大絕 CD 與角色控制不變。

## 魔物戰利品
- 擊敗魔物後進入拾取階段，掉落物會散落成可旋轉的 3D 發光模型。
- 玩家需要移動至掉落物附近才能取得；撿完後才開啟勝利結算。
- 每次擊敗魔物依物品類別各自抽取：主要素材 94%、次級素材 48%、稀有素材 19%、代表卡片首次 4%，每擊敗該種魔王一次，後續掉率再增加 5 個百分點（最高 100%）。若四項都未掉落，保底產生一份主要素材。
- 代表卡片為森棘龍卡片、霜牙獸卡片、熔冠翼龍卡片。拾取後累計至 `cards`，並以 `registeredCards` 永久記錄圖鑑發現狀態。

## 跨場景寵物

## 技術注意
- 改版沿用原存檔版本 `version:1`，在讀取時補齊新增欄位，不清除舊資料。
- GitHub Pages/瀏覽器同源 localStorage 是裝置本機資料，不是雲端帳號同步。
- 本機 Chromium 已驗證桌機／直式介面、已購武器長按選單、原生 GLB 掛接、手動拾取與卡牌登錄，以及離線嵌入音樂；實體手機與真實多指觸控尚未驗證。

## 原生資產與共用介面

`../models/tower/` 包含三類武器、鱗甲、晶角、精華瓶及收藏卡 GLB。模型來源為 `../authoring/tower-props.py` 與可編輯的 `.blend`，配置見 `../data/tower-props.json`。桌機與手機共用頭頂血條、圓形操作鍵與五個上方導覽按鈕；桌機以鍵盤移動，手機以觸控操作。

長按右下換武器按鈕，或電腦長按 V 約 0.45 秒，選取已持有基礎武器及已兌換的進階武器；方向鍵與 Enter 可選擇。短按循環已持有類型，1–3 僅能切換已解鎖的類型。

## 2026-10-14 卡片成長與魔王再戰

- **大絕招可用時**：僅在戰鬥中、冷卻完成、角色可行動且魔王在施放距離內，右下「大絕」會有金色高亮脈動；CD 中或距離不符不發亮，偏好減少動態效果的系統則顯示靜態亮框。
- **勝利畫面卡片強化**：原本消耗素材的 +15% 三級強化鍵改為消耗任意一張三種魔物代表卡片，永久提高一般攻擊與大絕傷害 1%，合計最多 +50%。使用者按一次只消耗一張，優先消耗目前最多的卡片種類。寵物兌換仍會消耗同一批卡片，已登錄圖鑑不會清除。
- **舊存檔兼容**：若存檔沒有 `cardAttackBonus`，將舊 `upgrade` 的等級按每級 15% 折抵，保留既有傷害進度且不重複疊加。之後購買卡片加成，最高上限為 +50%；特殊武器個別傷害詞綴仍各自生效。
- **魔王擊敗次數**：儲存 `defeatedCounts` 陣列，三隻魔王各自計算；舊存檔只能由首次過關記錄推得至少打敗一次，舊版本未記錄的重複擊敗次數無法精確重建。
- **逐次加強**：每擊敗某魔王一次，下次對戰該魔王 HP、攻擊傷害、有效防禦各 +5%；移動速度、攻擊頻率各 +2%；閃避判定由 20% 每次增加 2 個百分點，並保留原短暫閃避冷卻（機率上限 95%）。防禦加成以 `實際受傷害 = 原傷害 / (1 + 0.05 × 已擊敗次數)` 計算。
- **卡片掉率**：首次挑戰的代表卡片機率為 4%，之後第 2 次為 9%，第 3 次為 14%，依此類推，最高 100%。通關結算會顯示下一戰機率及魔王成長幅度。
- 已完成 JavaScript 語法及無頭邏輯模擬測試，包括首次血量 650、再戰血量 683、20%→22% 閃避、4%→9% 掉率、舊三級強化轉換為 45%、49%→50% 卡片購買與封頂驗證。手機真實操作及完整 3D 場景驗收仍需手動測試。
