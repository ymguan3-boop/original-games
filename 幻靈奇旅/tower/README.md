# 星穹挑戰塔

由使用者提供的《荒野獵境》離線 HTML 遊戲接入幻靈奇旅；原始下載檔保持不變。

- 三個挑戰樓層、怪物攻擊預警、耐力、素材掉落與武器強化沿用原引擎。
- 旅人主體使用 ../models/hero.glb，載入成功後才開始，沒有舊程序式人物備援。
- 走路、攻擊、受傷、翻滾使用 Blender 骨架動畫；武器掛接雙手前臂骨架。
- 進入目前武器射程即自動攻擊；右下「換武器」或 1–3 可切換大劍、雙刃、獵弓。
- WASD／方向鍵／搖桿移動；Space／翻滾鍵閃避；Q／回復鍵治療；R／大絕鍵施放大絕。
- 素材自動保存至此瀏覽器的 phantom-starspire-tower-v1，與原荒野獵境存檔分開。
- 點擊「返回初光鎮」回到主遊戲。請透過 HTTP／GitHub Pages 開啟，以便載入本地 GLB。
