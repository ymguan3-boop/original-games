## 進入與離開

在初光鎮河畔靠近山洞，按「探索山洞」進入。副本位於同站台 survivors/，首次進入提供召喚、商店、道具、自動補血、長按靈核球自動捕捉與武器操作引導，可略過，之後進入不自動重播。戰鬥中的「道具／暫停 → 返回初光鎮（存檔）」保存這場探險；回來可選擇續戰。

副本 BGM 與主遊戲「初光挑戰」共用 `../assets/audio/challenge.mp3` 及 shared-bgm.js。沿用音量與靜音設定；離頁停止，回城切回城鎮音樂，瀏覽器需玩家首次點擊後才允許播放。

## 任務與卡片換點數

- 河畔3對3釣魚擂台累積3場勝利，一次取得1000洞穴點數；旅人手冊引導到山洞。
- 再依引導讓小金魚進化、向釣手交換魚飼料，召喚並捕獲水蛟龍王，再一次取得1000洞穴點數。獎勵按存檔記錄防止重複領取。
- 寵物商人新增「卡片換點數」，選卡與數量後確認。每張第一階10／第二階25／第三階以上60點，與洞穴捕捉成功的卡片點數完全相同。兌換消耗羈絆卡數，不刪除圖鑑解鎖或編組；請保留要進化或交換飼料的卡片。原隨行寵物、坐騎及星耀球兌換保留。

## 存檔與共用物資

主遊戲與洞穴三種靈核球完全共用：普通 pokeballs、高階 greatBallCount、星耀 masterBallCount。購買、獎勵與捕捉都寫入主存檔 `phantom_journey_v1`；洞穴帳號與戰局保存在其中 firstlight，點數獎勵以冪等交易加入。各模式同一份存檔原子寫入，城鎮寫入會保留洞穴新資料並只合併實際資源差額。

第一次整合會備份舊洞穴 `phantom-endless-cave-v1`，保留點數、收藏、培育、背包與戰局，將舊洞穴三種球一次併入主庫存。主遊戲「重置遊戲」會一併重置洞穴並先備份，避免舊獨立資料被重新匯入；副本的測試重置只重置洞穴帳號為無寵物＋1000點，不更動共用球。正式頁面隱藏測試控制，開發者可用 ?qa=1 顯示。

資料保存在同一瀏覽器、同一網站來源；本機與 GitHub Pages 是不同來源，換網址或清除網站資料不會自動搬移進度。不同分頁同時修改副本時，舊分頁會停止寫入並提示重整。

## 現行戰鬥規則

- 主角初始雙槍；翻滾有完整動作與無敵判定。前五波敵人能普攻，第六波起施放專屬大絕。出戰幻靈優先支援主角目標；遠程依射程戰鬥，可保持距離。單體飛行物實際碰撞才扣血。
- 任意點存活幻靈卡可替換；倒下者須復甦。出戰者達門檻自動播放進化，備戰者可手動進化。卡片顯示生命、大絕紫色CD與完整被動。
- 黃卡1／紫卡2／紅卡3欄被動，依大絕主題配置；重複效果直接加總（20%＋20%＝40%）。每10級強化原欄位10%，不增加欄數。生命上限變動保持傷勢比例，不會換人補滿或復活。
- 同培育、等級、無外來隊伍加成時，黃三階基本能力不高於紫二階，紫二階不高於紅卡。配置與公式見 data/survival-passives.json、js/passive-rules.js、js/card-balance.js。
- 中毒4秒、麻痺0.9秒、緩速4秒、冰凍2.4秒且承傷剩20%、震退0.3秒，控制結束有0.65秒抗連控。五種狀態以Three.js立體粒子、幾何與光圈呈現，不載入狀態貼圖；回血只在實際恢復生命時顯示。
- 書本怪／寶箱怪擊倒只掉3D技能書／武器，主角拾取才增幅／裝備；掉落與授獎原子保存，特殊掉落不受普通180件上限清除。本局武器跨波保留，死亡或結算後清除。
- 重整可繼續同局；「再次挑戰」或結算後開始是新戰局，時間0／第1波／局內Lv1。帳號點數、收藏、永久武器、培育、未使用道具與遊玩紀錄保留。

## 開發與驗證

在本資料夾執行 `npm test`（Windows可用 npm.cmd），或 `node --test tests/*.test.mjs`。整合版105項邏輯測試包含共用球、單次遷移、重置防重匯、兌換冪等及跨模式寫入。

啟動 `node serve.cjs`（PORT 可設定埠號），開啟輸出的網址；此伺服器同時提供主遊戲所需的父層資產。正式部署沿用原站 GitHub Pages main 根目錄。

真實 Chromium 瀏覽器驗證腳本：tests/browser-v12.cjs、tests/browser-passive-v12.cjs、../authoring/check-cave-integration.cjs。PLAYWRIGHT_MODULE 與 CHROME_PATH 可指定環境，GAME_URL 指向測試站。測試用獨立瀏覽器儲存空間、受控生命與命中亂數驗證流程，不更動玩家存檔。

已驗桌面／320至1280寬度模擬視窗、實際商店購買、重整續局、新挑戰、WASD拾取、鹿家族雙方12種攻擊與五種動態狀態畫面。未進行實體 iPhone／Android 效能、耗電及自然連續20分鐘難度驗收；不能以軟體WebGL測試推論手機FPS。

美術提示詞與來源見 docs/imagegen-v11.md；完整被動清單見 docs/passive-catalog.md，已修正邏輯與後續建議見 docs/logic-review.md。舊開發腳本與暫存檔已移至工作區外的開發封存資料夾，正式版僅保留現行程式與測試。
