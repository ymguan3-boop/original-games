# 0.14 更新與抽驗

日期：2026-10-24。基底為已發布的 `7099025`。

- 捕捉飛卡改成完整5:7卡框，不沿用圖鑑的長版資訊排版。72 × 100.8px為原90 × 126px的4/5，翻卡及飛向點數區的中心位置同步修正。
- 所有共用場景讀取指示改成右下角32 × 32px，不遮罩或攔截操作；詳細載入階段、素材數與百分比保留於無障礙標籤及診斷。初始讀取佔位也縮小。等待戰場期間停用重複開始按鈕，避免讀取完成後重複開局。
- 召喚依實際幻靈獎勵中的最高卡色，從穿雲到揭曉加入大面積紫／紅光暈、放射光及旋轉光環；同抽有紅卡與紫卡時以紅光為主。抽率、費用及動畫總時間不變。
- 中毒、麻痺、緩速、冰凍、回血全部改用Three.js幾何、粒子、線段及動態光圈，停用生成狀態PNG。貼身效果跟隨角色，狀態結束時回收材質，共用幾何在場景結束時釋放。只有實際恢復生命才顯示回血。
- 教學只限帳號第一次進入洞穴的當次頁面。記錄firstVisitSeen；重整、回城再進、續局或新局不自動重播。舊帳號已有教學／首次召喚／戰局紀錄時視為已進入過。教學按鈕也只在首次頁面出現。

抽驗使用獨立Chromium資料，不改動玩家存檔：

1. 首次教學出現，離開／重整後不出現，之後開始戰鬥也不觸發。
2. 967與390寬視窗的讀取指示均為32px、靠右下且不大於翻滾鈕，pointer-events為none。
3. 實際捕捉成功後量測飛卡72 × 100.797px；卡框與卡片同高，完整資訊位於卡框內，翻卡與飛入錢包可完成。
4. 抽驗中毒、緩速、回血各有Three.js部件與不同動畫影格，回血只附著實際受治療主角。瀏覽器沒有請求任何五種舊狀態PNG。
5. 抽驗紫卡及紅紫混抽動畫，確認最高卡色與Canvas實際紫／紅像素，兩種畫面均有明顯對應光采。

上述5組抽驗通過，無頁面錯誤。依使用者要求未逐隻重驗全部角色；實體手機效能未驗。本機報告及截圖位於被Git忽略的qa/v14-*。
