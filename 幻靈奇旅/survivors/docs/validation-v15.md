# 0.15 圖鑑與副本進化機制

日期：2026-10-24。延續 0.14 的捕捉卡片、右下角小讀取條、紫紅轉蛋光采、Three.js 狀態特效及僅首訪教學。

## 圖鑑

- 從上至下完整分成黃卡、紫卡、紅卡，各區內按原圖鑑編號排序；可按卡色快速捲動。保留手機至少三欄與直向捲動。
- 每張卡片標示下一階的「戰局等級」門檻；點入詳情查看全系列進化鏈，也能點名稱查看其他型態。
- 進化資訊從實際 `data/evolution.json` 取得，與戰鬥共用規則；無後續型態時只標示最終型態，不顯示 JSON 的占位等級。
- 區分圖鑑的永久培育與副本戰局等級，並提供可展開的完整操作說明。

## 完整副本機制

1. 存活寵物獲得戰局經驗；出戰者完整、備戰者 60%，再套用被動與經驗雙倍晶。每級需目前戰局等級 ×25 XP，保留溢出經驗。
2. 一般三階系列在戰局 Lv.4、Lv.8 進化。特殊紫卡依該卡門檻；三色蛋→小麻→咕咕→小鷹→大朋依序為 Lv.4、8、12、16。卡色與進化階段各自判定，特殊鏈不改動原有卡色。
3. 出戰達標時自動播放原遊戲 3D 進化動畫，動畫期間暫停；備戰可點肖像的進化標示或長按卡片選手動進化。倒下者需先復活。一次跨越多個門檻時逐階播放。
4. 不消耗點數、卡片、素材；保留戰局等級、剩餘 XP、生命比例、大絕剩餘 CD、原編組的培育與訓練加成。基本能力、普攻、大絕、被動立即依新型態判定。
5. 圖鑑永久培育最高 Lv.50，每 10 級加強被動；它不直接觸發戰局進化。副本進化不會自行解鎖永久收藏或增加主遊戲卡片庫存。
6. 同局存檔續玩保留等級與進化；新挑戰由原編組型態、戰局 Lv.1 開始，永久培育保留。

### 金魚分支

小金魚戰局 Lv.4 時隨機進化為金魚國王或金魚皇后，各 50%；每次獨立，不可指定，不保證輪流出現。國王與皇后皆為此分支最終型態，沒有 Lv.8 再進化。

隨機決定移入進化存檔交易內，成功後立即保存；重整同一局沿用該結果。若動畫素材失敗，保留已完成的進化，提示清楚區分動畫失敗與進化未生效。

水蛟龍王不是國王或皇后的下一階。主遊戲需用兩種卡片各 3 張向釣魚郎換魚飼料，再到河邊召喚並捕獲；副本進化不會產生這些主遊戲卡片或魚飼料。
