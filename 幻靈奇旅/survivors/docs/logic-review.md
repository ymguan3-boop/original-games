# v0.11 邏輯檢查與建議

## 已找到並修正

|問題|修正與驗證|
|---|---|
|死亡或通關檢查點會阻擋足額購物|帳號道具／永久武器與已結束戰局分離；135點買30點藥水再買100點晶體，及1000點買狀態武器，實際扣點與庫存驗證|
|再次挑戰載回上一場戰鬥進度|明確區分「續同局」與「開始新挑戰」，後者新ID／時間0／第1波，保留帳號與歷史|
|重整後有未結束探險，召喚／編組只阻擋沒有出口|提供續玩、結算並繼續、取消；死亡檢查點自動正常結算後進入功能|
|擊殺直接給增幅／武器|改成實體掉落，接觸後才以同一筆交易授獎並移除掉落；特殊掉落重整可續留|
|普通掉落上限可能清掉珍貴書本或武器|只限制普通掉落，保留全部尚未拾取的特殊掉落|
|普通元素攻擊暗中附加狀態，卡色欄數不明|改為逐隻大絕主題配置的1／2／3欄；無隱藏元素被動，重複能力線性加總|
|每10級額外增加能力，突破卡色欄數|改為既有能力強化10%，不新增欄位|
|只顯示某些被動，實際生命／攻擊／防禦或射程沒有一致套用|統一自身、備戰隊伍與出戰命中的適用範圍；生命與培育按共同公式重算並保留受傷比例，射程同步用於索敵與釋放|
|換人或換武器可能竄改飛行中攻擊效果|彈體記錄釋放者能力，碰撞時沿用；換武器取消舊蓄力與連段，但不刪除空中彈體|
|使用所有自動道具都播放治療視覺|只有實際增加生命的角色才記錄回血，不把增幅／電池或攻擊當治療|
|新局殘留舊模型或延遲載入的怪物|世代與戰局ID隔離非同步載入，重開清除舊角色、動作、狀態與掉落視覺|
|反覆生成道具掉落時新增瓶蓋幾何資源|改為共享固定幾何，避免累積資源|

## 已確認保留的規則

- 前五波仍會普攻，第六波才使用魔物專屬大絕。
- 冰凍2.4秒、麻痺0.9秒；冰凍時受到的傷害剩20%。冰凍降低輸出是既定規則，不是光球沒有命中。
- 死亡不會被被動恢復或自動藥水拉回；倒下寵物需要復甦藥。生命上限增加、升級或換人不會復活。
- 控制結束後0.65秒短暫抗連控，避免無限麻痺／冰凍。
- 捕捉命中才結算，失敗停滯1秒；捕捉獎勵與擊殺掉落分開，不重複發放。
- 書本／武器拾取及商店購買存檔失敗時完全不扣費、不刪掉落、不套用能力。
- 同來源更新與重整保留檢查點；換埠號或換瀏覽器是另一份本機儲存。

## 建議，尚未實作

1. 增加特效強度／效能設定：目前五種動態貼圖均已實際使用，可再讓手機降低重疊特效與粒子密度。這需要實體手機量測，桌面軟體WebGL不能代表手機效能。
2. 增加存檔匯出／匯入。現階段資料保存在瀏覽器，清除網站資料仍會失去遊玩存檔；手動測試重置已先另存備份。
3. 結算畫面增加傷害、控制與治療統計，累積實際試玩資料後再平衡。不同被動類型無法只靠百分比直接比較強弱；目前已驗證同投入的基本能力與同類被動級距。

本檢查覆蓋已列出流程及自動測試，不代表所有裝置或所有長時間操作組合均已驗證。此為0.11邏輯檢查紀錄；0.12已接回主遊戲，現行入口及存檔規則見README。
