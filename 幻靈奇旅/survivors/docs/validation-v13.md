# 0.13 更新與驗證

2026-10-24。以已發布的 `0497cc2` 為基礎，未改動玩家存檔格式或靈核球共用規則。

## 更新

- 三項洞穴任務統一標為第六步；釣魚勝場任務直接導航至河畔，抵達判定使用實際可釣魚範圍。釣魚郎所有「魚飼料」「水蛟龍王」文字以行內粗體呈現。
- 旅行指南新增完整洞穴流程、兩筆1000點任務、商人換卡、共用球與自動操作說明。廣播攻略加入相關公告，首次攻略約20秒出現，後續維持原輪播間隔。
- 商人換點數改六個分類：黃卡1／2／3階、紫卡1／2階、紅卡，不顯示肖像。紫卡高階型態歸入第二類、紅卡各階合併；點數仍依每張原始階段10／25／60計算。按圖鑑順序扣除，兌換前可展開逐張明細，扣卡與給點同筆交易。隨行寵物新增與坐騎相同形式的圖示。
- 釣魚擂台改用3D河岸、水波與碼頭，搭配內建生圖背景。魚類在所有3對3擂台均有貼地水灘，與角色水平移動同步，並於角色移除時釋放材質。
- 副本首頁不再等待3D引擎、模型、武器與狀態美術。玩家開始戰鬥才載入3D；必要模型並行取得、原遊戲模型URL一致以利快取，狀態貼圖獨立載入。招式資料與3D特效模組分離，避免首頁過早載入渲染依賴。
- 主遊戲、室內、擂台、初光挑戰、副本戰鬥、星穹挑戰塔與Blender模型室加入共用LOADING進度；顯示實際載入階段及已完成素材項目。百分比是依階段與已知項目估算，不是假計時。瀏覽器返回上一頁不會殘留遮罩。
