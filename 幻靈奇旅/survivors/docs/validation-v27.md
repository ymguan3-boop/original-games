# v0.27：洞穴原模型動作、瞬間回血與高階黃卡編成

日期：2026-10-26。基底：`515a9129621817bcb8055f6a1a43e5fac5e474e2`。

## 改動與邏輯核對

- 水蛟龍王強制使用原GLB的Attack／Ultimate完整片段，1倍速，時間1.9／5.8秒，出手0.75／2.9秒；不再由後續卡牌對照改寫動作，播放前清除上一動作權重。口部發射點依原製作資料定位，補足水彈與水柱，保持原範圍傷害。
- 歐頭慢原生模型被判定已有特效，但BeamPose不會顯示模型內建光束，而一般投射特效也因此被略過。本版普攻BeamPose、大絕Beam，1.1秒出手，補上白光／七彩光束；保留大絕貫穿及全場麻痺。兩者在原動作期間暫停追擊移動，避免身體漂走；敵我兩方同樣適用。
- 洞穴歐頭慢尺度乘2.1、小山乘1.3；只更改洞穴模型高度規則，沒有改原始模型與主遊戲體型。血條定位及可視範圍約束沿用同一高度；首領既有1.5倍另外保留。
- 瞬燃雙刀範圍+60%，仍與本局範圍增幅乘算，保留燃燒與原掉落資格，被動文字自動反映。
- 一次性寵物治療用獨立大型十字、直立光柱及爆發環，持續1.4秒並跟隨主角；實際回血為零時不播爆發。不寫入持續回血顯示計時，持續型治療仍使用原小型上升效果；只有新加強的十字使用不受燈光沖淡的材質。
- 一般魔物只用黃卡，書本／寶箱走原有特殊池。第4波起混二階，第8波起混三階，仍有一階；各比例見README。紫卡所有階段可作小魔王（包含資料stage=4的大朋）；大魔王僅紅卡，保留先前指定三色蛋排除。不改每5／10波首領數、8%成長、200／300點、武器機率、捕捉規則與同場上限。
- 名單空缺時不再退回錯誤卡色；候選名單依靜態資料物件快取，減少每次出生反覆掃描。沒有新增模型、貼圖、圖片或音訊下載，沿用64組／640網格池上限及材質回收。
- 遊戲指南、README與模組快取版本同步。主遊戲只更新洞穴入口版本，模型室、主遊戲擂台、原GLB／原生控制器檔案皆保持原樣。
