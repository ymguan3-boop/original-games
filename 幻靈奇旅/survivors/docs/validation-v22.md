# 無盡洞穴 v0.22：燃燒、瞬移與魔王永久武器

日期：2026-10-25。基底：`29bf6a0`；僅修改洞穴玩法，主遊戲只更新副本入口的快取版本。

## 本版規則

- 敵方生命與攻擊逐波以 `1.08^(波次-1)` 複利增加；第1波基準、前版敵方3倍基礎血量、生成頻率1.5倍與同場36隻一般魔物上限維持。寵物不套用。已出現的敵人保留原生成數值，不因載入更新而突然回血。
- 燃燒：持續4秒，每秒一次傷害，傷害依來源攻擊力計算並經防禦減免；本版燃燒武器的每次持續傷害基值為攻擊力30%。重新附加刷新時間，不建立多份同類燃燒。冰凍的80%減傷及捕捉留手保護照常適用。
- 焰紋大劍：普攻／大絕命中35%機率燃燒。潮流單刀：移除共用震退，改為40%機率緩速4秒，移速減半。
- 所有單刀大絕優先找最近的有效魔物，瞬移至其前方再連斬；沒有目標不消耗冷卻。場地邊緣改選場內位置，避免與魔物重疊。普通單刀大絕僅最後一擊震退，避免第一擊就將敵人推離後續連斬。
- **瞬燃雙刀**：每次普攻起手自動選最近有效魔物、瞬移近身，快速周身連斬；命中100%燃燒。大絕沿用雙刀連擊，起手也會接近最近敵人。
- **幻燃單刃**：與雙槍完全相同的起始射程及範圍增幅計算，發出真正移動且可貫穿多個魔物的直線劍氣，命中100%燃燒。大絕仍遵循單刀瞬移規則，改以連續貫穿劍氣攻擊。
- 兩把新武器僅由每5波小魔王／每10波大魔王在**擊敗時**掉落。每隻小魔王擲一次5%、每隻大魔王擲一次10%；成功再等機率隨機選一把，並非每把各擲一次。普通魔物、寶箱、書本、捕捉結算、轉蛋及商店購買均不供應。
- 掉落先生成可見的武器物件；主角拾取或使用萬象吸取後才永久入庫並裝備。第一次取得每把武器會顯示解鎖彈窗，確認後保存已讀狀態；重整不重播，重複拾取走原有融合規則，不再提醒。
- 密碼測試入口沿用；重置選項改成「重置＋5000點＋2把武器」。重置仍備份原洞穴存檔、清除寵物與首次領取紀錄，保留主遊戲共用靈核球，並直接持有兩把新武器。測試授予不觸發取得彈窗。

## 特效與效能

- 火焰使用共用旋轉曲面幾何與平滑材質，每名燃燒角色5道火焰＋1道光環，不讀取狀態圖片、不新增粒子貼圖或燈光。
- 狀態特效離開可見區即釋放，傷害仍由戰鬥邏輯持續計算。劍氣使用既有 InstancedMesh 管線與共用弧形幾何，不為每一發建立獨立模型／材質；原雙槍點狀彈道保持。
- 瞬移光環沿用既有特效物件池與數量上限。清理本次改動後未使用的攻擊設定匯入及選擇目標變數；保留動態載入的原版模型、動畫與遊戲素材，未任意刪除原始資產。
- 新武器圖示為小型手繪SVG，無額外生圖或模型服務；更新所有改動模組的版本參數，避免瀏覽器混用舊版依賴。
