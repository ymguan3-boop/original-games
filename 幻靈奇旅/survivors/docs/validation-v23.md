# 無盡洞穴 v0.23：被動調整、四把限定武器與大蔥

日期：2026-10-25。基底：`9c5bf55`。主遊戲只更新探索山洞入口的版本參數，其他變更均限洞穴。

## 規則

- 森影雙刃：主角用該武器造成每次實際擊殺，回復主角最大生命5%，不超過上限、不復活；寵物擊殺及捕捉留手不觸發。同一敵人的重複結算不重複回血。
- 瞬燃雙刀：取消普攻與大絕起手的瞬移，改為攻擊範圍+30%，保留100%燃燒。武器範圍加成與現有範圍增幅相乘，地上範圍圈與實際判定共用數值。
- 雷鳴雙槍：主角暴擊率增加10個百分點，仍遵循一般暴擊上限；不加給寵物。
- 巡林單刀與雙月刃：購買價格0點，需點擊領取後永久持有。因價格為0，自動排除於付費轉蛋武器池，避免花點數抽到免費武器。
- 商店可購買武器由上至下高價到低價，即由下至上低價到高價。同價保留原排序，魔王限定收藏獨立標題列於可購買區後方，不把限定武器標成0點可購買。
- 萬象吸取：售價200點；開啟自動使用後，首次有掉落物即可使用，此後至少每10秒可使用一次，每次消耗1件。空場不消耗；暫停不計時間。自動使用時間與庫存扣除同筆存檔，重整保留剩餘間隔；舊版「每局一次」標記不阻擋新規則。手動使用仍可立即執行。
- 必暴雙槍：100%暴擊，命中40%震退；普攻與大絕沿用雙槍貫穿彈道。必暴明確繞過一般65%暴擊率上限；已發射子彈保存發射時的被動，切換武器後不追溯改寫。
- 大蔥：攻速+50%，命中50%麻痺0.9秒。普攻間隔、出手點、動作播放速度及大絕連擊間隔一併加速；大絕冷卻與傷害倍率不變。沿用大劍範圍普攻與全場大絕，麻痺沿用原有控制免疫間隔，避免永久控場。
- 四把永久限定武器：瞬燃雙刀、幻燃單刃、必暴雙槍、大蔥。每隻5波小魔王擲一次5%，每隻10波大魔王擲一次10%，成功後等機率四選一。非四把各自擲骰；普通敵人、寶箱、書本、捕捉、商店與轉蛋不供應。
- 主角拾取才入庫及自動裝備，每把首次取得顯示一次性彈窗；確認後存檔已讀，重複拾取走既有融合。密碼測試重置為「5000點＋4把武器」，保留共用靈核球，清除寵物與保底領取紀錄。

## 模型、資源與邏輯整理

- 大蔥直接以Three.js程序幾何建立，沿用大劍握點、動作與長度方向；白色蔥身、綠色蔥葉與根鬚可在實際手持及掉落中看見。預算為9個mesh、1184個三角面、0張貼圖；模板建立一次，掉落複本共用幾何及材質。
- 順便修正掉落模型複製手持模板時繼承隱藏狀態的問題，明確將掉落複本設為可見；大蔥掉落保留原色，不套通用金銀色材質。
- 移除取消瞬移後的死分支，集中武器射程與攻速設定供戰鬥邏輯共用；大蔥只替換外觀，保留Sword動畫狀態，不新增渲染迴圈、燈光、貼圖下載或模型請求。
- 新圖示為小型SVG。保留仍被動態載入的模型、動畫及舊版必要素材，沒有為了清檔而刪除遊戲資產。QA報告及截圖在忽略的`survivors/qa/`，不隨發布上傳。
