# 0.17 洞穴戰鬥、進化、飛行與載入改善

日期：2026-10-25。所有本頁招式／被動／進化改動限洞穴副本；主遊戲幻靈技能與進化不變。主遊戲僅一般幻靈與河畔釣魚3對3擂台加速1.3倍，初光挑戰、城鎮及洞穴時鐘維持原速。

## 主角與呈現

- 移除場地中央固定圈與主角腳底白圈；鎖定魔物提示保留。紅圈跟隨主角，半徑和傷害判定共用範圍公式，含衣櫃、被動、增幅／道具。
- 基礎普攻半徑：雙刀周身2.4、單刀單體3.2、大劍扇形4.2、雙槍12.6（大劍3倍）。單刀同階單體傷害最高並震退；雙槍實際貫穿沿途魔物，各目標每彈只中一次。
- 大劍大絕無需目標，三次全場攻擊，最後一次鏡頭震動。所有武器和寵物使用Three.js平滑金屬幾何特效，區分普攻、大絕與暴擊；光球／光束追蹤模型身體並實際接觸才扣血。
- 武器普攻、大絕、落地尾擊及寵物屬性音效使用本機WebAudio合成，沿用音樂靜音／音量，第一次操作才解鎖。瀏覽器訊號量測四種武器均有非零聲波；未以此宣稱主觀聽感驗收。
- 小黃體型為原來2/3。11隻實際鳥類移動使用原生Fly或程序飛行，包含各辣椒雞、雛鳥家族、小麻／咕咕／小鷹／大朋及光鳳鷹；三色蛋、青蛙與其他非鳥類不套用。

## 進化與被動

- 圖鑑保持黃→紫→紅分區，同色內依實際進化家族／深度排序，完整顯示分支與門檻；紫／紅卡說明底為對應半透明色。
- 三色蛋Lv4各1/3隨機進化小麻、咕咕或小鷹。小麻Lv8、咕咕Lv12、小鷹Lv16可直接進化大朋；不再把三隻不同鳥誤列為逐階進化。
- 小麻／咕咕／小鷹／大朋繼承回血及防禦兩種被動，符合紫卡兩欄；防禦採專用平衡倍率以維持黃3≤紫2≤紅卡。施放大絕額外令主角暴擊率×2持續20秒，再施放刷新、不疊倍，既有65%暴擊率上限保留。不是暴擊傷害×2。
- 小金魚Lv4等機率進化金魚國王／皇后，兩者Lv15進化水蛟龍王；不會因此觸發主遊戲魚飼料、召喚與捕獲獎勵。
- 進化成C老猴、水仙子、冒險蛙與龐克兔的門檻統一Lv10，即C囝仔→C老猴、水毛蟲→水仙子、大眼蛙→冒險蛙、小黃→龐克兔。這四者在現有資料是終階，沒有捏造新的後繼形態。
- 戰局Lv、帳號培育Lv沿用既有區分；出戰到門檻自動進化並播放動畫，備戰可手動。

## 清理與效能

- 僅刪除確認無執行與測試引用的5張舊狀態PNG及1張舊大絕PNG，共14,024,675 bytes（約14.0MB）；保留原模型、肖像、來源、作者工具及必要相容模組。
- 去掉首場仍下載的大絕PNG，減少2,794,776 bytes（約2.8MB）首場下載；三種靈核球模型改為並行準備，武器特效不另外下載圖片。
- 移除未使用的舊特效更新循環，幾何／材質共用、Mesh池最多640、瞬時效果最多64，投射物與掉落數沿用上限，切場釋放資源。
- 修復Three r128 InstancedMesh先設count=0造成instanceColor零長度與投射物黑色／缺色的問題。
- 以上是可證明的資產與程式改善，未宣稱所有手機都達固定FPS或長時間完全不掉幀。
