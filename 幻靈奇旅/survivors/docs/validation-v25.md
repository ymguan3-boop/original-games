# v0.25：洞穴寵物輔助大絕、自動施放與永久武器成長

日期：2026-10-26。基底：`c756726ae2faaf40488969e95fa734bd485d499b`。範圍為無盡洞穴；主遊戲只更新旅行指南與入口快取參數，擂台、主遊戲進階條件與原有模型素材均未修改。

## 改動與邊界

- 大絕規則集中於`pet-ultimate-rules.js`，技能詳情及探險指南從同一規則生成。回血、減傷替代型大絕在模型動作釋放點執行，不再執行原傷害／90%回血分支；新增型技能保留原攻擊並加入效果。
- 同類持續回血、減傷盾取較強倍率並刷新10秒；一次盾最多1次，抵擋下一次實際傷害，翻滾不消耗。暴擊增加只套用主角，三色蛋分支既有×2／20秒保留。全場狀態作用於施放當下現存魔物，沿用抗連續控制規則與冰凍減傷80%。
- 長按卡牌550ms開關自動大絕；ⓘ開啟詳情及手動進化。自動施放左至右換上出戰、跳過倒下／冷卻／無目標者，等待當前動作及持續連鎖結束；設定存檔。排程直接更新戰局，避免每幀交易複製造成參照失效；手動換人清除離場技能。
- 指定七個進化前身全部調整為Lv.8，小麻及咕咕維持終點。圖鑑、教學、洞穴指南、主遊戲旅行指南與README同步更新。
- 魔王限定武器重複拾取後永久攻擊+1；採原子拾取交易並隨帳號存檔，首次取得才彈窗。新重複不再增加融合15%；保留既有存檔的本局融合。轉蛋退點與寶箱本局武器規則不變。
- 新增池化Three.js護盾／增益與全場狀態波，沿用既有特效數量上限及共用幾何；沒有新增圖片／GLB下載。兩層護盾球殼使用低透明度，保留主角辨識度；手機狀態列可換行。
