# 十關魔王語音與對話設計

由 `js/boss-openings.js` 產生（`node defense/tools/make-docs.mjs`）。每位魔王只說 1 句（8～18 字），開場在戰場畫面完成、發牌開始後出現，顯示 3.2～4.2 秒後自動淡出，也可點 × 關閉。

## 對話框

- 鄉村風：木框、麻布紙卡、手繪虛線邊、底部草葉；標題列為「第X關｜關卡名｜魔王名」。
- 底框顏色取自各魔王外觀主色（`theme`：木框 wood、紙卡 paper、強調 accent、字色 ink、頭像光暈 glow）。
- 頭像不是圖鑑卡，而是用該魔王自己的 3D 模型（GLB）即時渲染的透明胸像：`view.portrait(id, pose)`，每關載入時先渲染一次並快取，開場時嵌入對話框；若渲染失敗才退回圖鑑卡圖。
- 手機直式：框寬滿版、頭像 96px；手機橫向：框寬約 58% 螢幕、貼在上方 HUD 之下，不遮擋卡牌與主戰場。

### 逐位說明

**第1關｜初光草原｜小黃** — 「嘿！先追上我再說！」
- 聲音：男孩，約 7～10 歲；活潑淘氣；語速偏快，尾音俏皮；情緒愛惡作劇的小朋友。像追著你跑的小孩，結尾上揚。
- 透像姿勢：yaw 0.5、動作 Attack、取景 zoom 1.05

**第2關｜青蛙池塘｜大眼蛙** — 「呱！別把池水弄髒喔！」
- 聲音：男孩，約 8～10 歲；圓潤柔軟；語速中快；情緒可愛、護池塘。開頭帶青蛙擬聲「呱」，比小黃更圓潤。
- 透像姿勢：yaw 0、動作 Idle、取景 zoom 0.72、focus 0.34

**第3關｜水仙瀑布｜水仙子** — 「水花會替我迎接你。」
- 聲音：少女／年輕女性，約 18～22 歲；溫柔清亮、帶仙氣；語速偏慢，像吟唱；情緒優雅、空靈。唯一的女聲；整體放慢，尾音拉長。
- 透像姿勢：yaw -0.5、動作 Idle、取景 zoom 2.3、focus 0.1

**第4關｜猴王果園｜C老猴** — 「想過關？先接我一招！」
- 聲音：男孩／年輕男聲，約 10～15 歲；機靈挑釁；語速快，語尾上挑；情緒頑皮、愛逞強。帶猴子的機靈感，句尾挑釁。
- 透像姿勢：yaw 0.45、動作 Attack、取景 zoom 1

**第5關｜雷鳴工坊｜龐克兔** — 「來吧！聽我的雷鳴節拍！」
- 聲音：中性偏少年，約 15～18 歲；搖滾、張揚；語速中快，有節奏；情緒自信、喊麥感。像舞台上開場喊話，字字有重拍。
- 透像姿勢：yaw -0.35、動作 Attack、取景 zoom 1

**第6關｜牛仔荒野｜阿宏牛仔** — 「荒野規矩，由我來定。」
- 聲音：少年，約 14～17 歲；瀟灑自信；語速中慢，吐字清楚；情緒西部英雄感。稍微壓低，帶一點牛仔的懶洋洋。

**第7關｜星輝觀星台｜藍金星輝法師** — 「星光，已經替我回答了。」
- 聲音：青年男聲，約 25～30 歲；穩定、神秘；語速偏慢，像宣告預言；情緒知性、篤定。句中停頓，像在念星象。
- 透像姿勢：yaw -0.4、動作 Idle、取景 zoom 1.5、focus 0.2

**第8關｜月影森林｜綠眼蝙怪** — 「夜色，最適合狩獵了。」

- 透像姿勢：yaw -0.3、動作 Idle、取景 zoom 1

## 語音檔

- 資料欄位（每位魔王的 `voice`）：`voiceName`、`voiceKey`、`genderFeel`、`ageFeel`、`tone`、`speed`、`emotion`、`pitch`、`rate`、`notes`、`audioFile`、`ttsText`。
- 播放：遊戲讀 `defense/audio/boss/<voiceKey>.mp3`；播放時 BGM 自動壓低。若檔案不存在，退回瀏覽器內建的 zh-TW 語音朗讀同一句（音調與語速依 pitch / rate 換算）。尊重「音效靜音」設定。
- 產生：`defense/tools/make-boss-voices.cjs` 使用 Edge 神經語音 zh-TW-YunJheNeural（雲哲）產生男聲；水仙子用 zh-TW-HsiaoChenNeural（女聲）。需要先 `npm i ws` 再 `node defense/tools/make-boss-voices.cjs`（可只指定部分，例如 `... meadow pond`）。台詞或聲音改了就重跑一次。
- 背景音樂：守護戰的選島畫面與戰鬥都播放本遊戲主題曲（`assets/audio/general.mp3`）。
