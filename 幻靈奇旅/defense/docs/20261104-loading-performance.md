# 守護戰載入與音樂修正

- 海圖樣式移至共用洞穴樣式之後，並以 `body.defense-scene` 固定海圖容器與快捷列，避免共用 `#lobby` padding / button 規則覆蓋。
- 城鎮沿用已開始的跨頁轉場，不重新開始第二段；同一轉場期間隱藏下層舊讀取介面，直到第一個場景畫面準備好。
- 守護戰獨立混音，移除洞穴專用 5.5% 音量上限；保留玩家音量及靜音設定，攻擊時只做短暫適度降音。
- 海圖不再提前建立隱藏戰場 WebGL renderer 或音效引擎；背景僅預載資料，出擊時才建立戰場。
- 同時讀取資料與 Three.js。首屏優先目前島嶼、碼頭及快艇，其他島嶼限制兩個並行且讓出主執行緒；戰鬥及隱藏分頁暫停選用的海圖工作。
- 島嶼模型先顯示，卡圖另行補入，卡框圖片只建立一次載入 Promise。失敗素材可再次載入。
- 61 張卡圖縮為 320px WebP 預覽：8,753,358 → 1,591,466 bytes（減少 81.8%）；卡框 PNG 1,717,649 → WebP 108,662 bytes。保留所有原圖。
- 網站同步時將守護戰模型、頭像、預覽卡圖及主題曲部署為靜態素材，減少冷啟動時經 GitHub 轉送。

依使用者要求，不再執行畫面及操作驗收；交付前只執行必要程式檢查、既有測試與建置。未宣稱實機載入秒數或 FPS 提升幅度。
